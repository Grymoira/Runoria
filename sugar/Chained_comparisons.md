
# 链式比较 chained comparisons

这是非常常见的一种方式
就不做过多的赘述了

```py
# 这就是一个链式比较的方式
if 0 < x < 10:
    pass
```

在大多数的编程语言中，你必须使用逻辑运算符`&&`来连接两个比较

传统的写法：
```py
if x > 0 and x < 10:
    pass
```

## 依旧是后日谈

在python中，在处理`0 < x < 10`的时候，
实际上会将其转化为`(0 < x) and (x < 10)`
但是会有一个非常细微的优势：就是中间的变量x只会被计算一次；
如果x是一个复杂的函数调用结果，链式比较不仅更加的美观，而且更加的高效

链式比较不仅仅限于两个比较级，你可以尝试写得更加的冗长，甚至是混合符号：
```py
# 虽然这种方式在语法上合法
# 但是还是建议保持逻辑上的清晰
if 100 >= score > 60 != 0:
    pass
```

这其中有一个逻辑细节上的陷阱：
虽然你可以写成`a < b > c`，但是在逻辑上非常的容易让人困惑（只要对方学习过小学的数学）
我们通常只在单向递增或者递减的区间判断中使用链式比较
像是这样：`min < x < max`

## 经验谈

这种语法糖和三元运算符是一样的目的，即减少视觉上的噪音，让代码能够一眼看上去就是在描述问题的核心，而不是在堆砌逻辑
