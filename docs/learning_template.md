## 7. 根目录 README 同步摘要（必需）

新增任何算法时，在仓库根目录 `README.md` 同步补充独立可读的章节，至少包括：

- **问题背景与直观思路**：为什么需要该算法？与普通方法有什么差异？
- **核心步骤或推导**：必要时用数学公式、伪代码及手算示例解释。
- **可独立运行的 Python 示例**：包括必要导入和预期结果，由 CI 执行验证。
- **算法性质**：最好/平均/最坏时间、额外空间、稳定性（如适用）、是否修改输入、输入范围。
- **使用与局限**：什么时候适合学习或使用，什么时候应该优先采用标准库。
- **仓库链接**：指向专题笔记、实现、测试与可选基准实验。

其他知识主题同样需要在首页添加有实质内容的总结，不应只添加导航链接。
